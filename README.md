# MacSleepWatcher

Mac の画面の ON/OFF とスリープを、ターミナルに日ごとの帯で出す。標準の `python3` だけで動き、追加のパッケージは不要である。

## 使い方

リポジトリ直下で実行する。内部で `pmset -g log` を読むため、表示まで数秒かかることがある。

```bash
python3 sleepwatch.py
```

今日を含む直近の日数を出すには `-d` を付ける。`pmset` が保持している期間だけが対象で、この環境では約1週間分だった。ログが始まる前の時刻は `·` になる。

```bash
python3 sleepwatch.py -d 7
```

日付を指定すると、その日だけを出す。`-d` を同時に付けても、指定した日だけになる。

```bash
python3 sleepwatch.py --date 2026-10-03
```

幅を固定するときは `--width` を付ける。値は 14 以上にする。省略するとターミナルの幅に合わせる。端末に直接出すときは、画面ONを黄、稼働をシアンで塗る。パイプやファイルへ出すとき、または `--no-color` を付けたときは色を付けない。

```bash
python3 sleepwatch.py --width 100 --no-color
```

## 帯の見方

1日につき見出しと2行が出る。見出しの時間は、その日の画面OFFとスリープの実時間で、小数第1位までである。帯の1マスは十数分で、幅が狭いほど粗くなる。今日のうち、現在時刻より後は空欄のまま残す。状態は日をまたいで引き継ぐ。

`█` は画面ON、または稼働である。`░` は画面OFF、またはスリープである。`·` は、その系列の記録が始まる前である。画面と電源は別の帯なので、画面が消えてからスリープに入るまでの間は、画面の帯だけが `░` になる。

画面の帯では、そのマスに少しでも画面OFFがあればマス全体を `░` にする。電源の帯も同様に、少しでもスリープがあれば `░` にする。数秒のスリープは、帯の上では1マス分に見える。見出しの時間は、この粗さとは別に実時間を足している。

## 何をスリープと数えるか

`Entering Sleep` から、区分が `Wake` の行までをスリープにする。`DarkWake to FullWake` も、この区分 `Wake` に含まれる。区分 `DarkWake` の保守起床と、`Wake Requests` は、スリープを終わらせない。

`Entering DarkWake` だけの区間はスリープに数えない。画面が消えていれば、画面の帯には出る。
